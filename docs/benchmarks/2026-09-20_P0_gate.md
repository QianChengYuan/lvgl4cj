## 4. 本次门禁发现并修复的缺陷（原始数据之外的结论）

门禁的价值在于**发现问题**，而不只是把绿灯贴上去。t8 期间由 ASan / 泄漏门禁
真实抓出并修复了 4 个问题：

| # | 问题 | 发现方式 | 影响 |
| --- | --- | --- | --- |
| 1 | `lvglcj_style_delete` 释放仍被存活对象引用的样式 | ASan：`heap-use-after-free`（`lv_obj_delete → lv_obj_get_style_width → get_prop_core`） | **静默内存破坏**：普通构建下不一定崩，可能只是尺寸/颜色错乱。已改为「仍被引用则拒绝释放」并报出引用者数量 |
| 2 | `test_sdl2_backend` 的 flush 缓冲按 area 紧凑尺寸分配（8 KB），却把 display 的 `stride=640` 交给 SDL 按行读 | ASan：`global-buffer-overflow`（128 字节 memcpy） | 用例越界读。已按 stride × 高度分配，并加显式不变式断言 |
| 3 | 父对象删除时 `INVALIDATED` 子表项**无上限增长**（10 条/轮，完全线性） | `test_leak` 实测曲线 | 直接违反 §11.1 的 soak 判据「句柄收敛」。已实现最旧优先的有界回收（上限 1024、低水位 768） |
| 4 | `ht_release_unlocked` 对 `INVALIDATED` 表项也去摘反查表，而该地址已被新对象复用 | 引入 #3 的回收后由 `test_leak` 门禁② 抓出（ALIVE 增量不再为 0） | 误删新对象的反查项 → 同一原生对象出现两个句柄 → ALIVE 单调增长。**这是既有代码的潜伏缺陷**，回收器只是让它变频繁 |

### 4.1 ASan 与仓颉运行时的硬不兼容（对 §9.5 原方案的有据修正）

§9.5 原计划让 ASan 覆盖「C 桥接层 + LVGL + 仓颉」的混合进程，用 suppression
屏蔽仓颉运行时符号。实测这条路走不通：

```
AddressSanitizer: CHECK failed: sanitizer_thread_arg_retval.cpp:56 "((t)) != (0)"
    #4 pthread_join                      (ASan 拦截器)
    #5 CJ_ScheduleAllNonDefaultExit      (libcangjie-runtime.so)
    #6 CJ_ScheduleExitMode
    #7 CJ_ScheduleStop
    ...
```

仓颉运行时的线程由自身机制创建，ASan 的线程簿记中没有对应记录，
退出时 `pthread_join` 的一致性检查必然失败并**中止进程**。
`detect_leaks=0` 也避不开（该簿记不由泄漏检测开关控制）。

**处理**：ASan 边界划在 C 侧（纯 C 进程），混合进程改用 valgrind（§9.5 第 5 点的既定回退）。
这不是降低标准 —— 本层所有手工内存管理都在 C 侧，C 单测会走遍它们，
该边界对「我们自己的代码」是完整覆盖，且不依赖仓颉 SDK，CI 上更稳定。

## 5. 复现方式

```bash
source scripts/env.sh                      # 或自行设置 CANGJIE_HOME
bash scripts/gate.sh                       # 全部七项（约 10–15 分钟）
bash scripts/gate.sh --quick               # 只跑 cjfmt/cjlint/build/test（约 2–3 分钟）
```

单独的原始数据：

```bash
# C 单测（含检查项数）
for t in test_handle_table test_queue test_display_indev test_null_backend \
         test_sdl2_backend test_style_widgets test_anim test_leak; do
    printf '%-22s ' "$t"; "$HOME/lvgl4cj-build/bin/$t" 2>&1 | grep -E '项检查' | tail -1
done

# ASan（需先构建：cmake -S native -B $HOME/lvgl4cj-build-asan -DLVGLCJ_ASAN=ON -DLVGLCJ_BUILD_TESTS=ON）
ASAN_OPTIONS=detect_leaks=1 "$HOME/lvgl4cj-build-asan/bin/test_leak"

# valgrind（混合进程；判定见 §3.4）
LD_LIBRARY_PATH=libs valgrind --leak-check=full --error-exitcode=42 \
    --log-file=/tmp/vg_hello.log examples/hello_cj/target/release/bin/main --smoke
```
